================================================================================
QUICK REFERENCE: STATUS CODES
================================================================================

200 OK - Successful GET, PUT, PATCH operations
201 Created - Successful POST (resource created)
400 Bad Request - Validation error, duplicate, business rule violation
401 Unauthorized - Missing or invalid authentication
403 Forbidden - Insufficient permissions (RBAC denial)
404 Not Found - Resource doesn't exist or inactive

================================================================================
TROUBLESHOOTING
================================================================================

Problem: 401 on all requests
Solution: Click [Authorize], enter credentials, get token

Problem: Token expired
Solution: Re-login (tokens last 30 minutes)

Problem: 404 on asset/user not found
Solution: Make sure resource exists and is_active=true

Problem: Can't create duplicate asset tag
Solution: Use unique asset_tag values each time

Problem: Assignment fails
Solution: Ensure asset status is "Available" and user is_active=true
