HOW TO ACCESS SWAGGER UI:
--------------------------------------------------------------------------------
1. Ensure backend server is running:
   python -m uvicorn app.main:app --reload --port 8000

2. Open browser to: http://localhost:8000/docs

3. You should see the Swagger UI interface with all API endpoints listed


AUTHENTICATION STEPS:
--------------------------------------------------------------------------------
Step 1: Click [Authorize] button (top right corner)
Step 2: Enter credentials in the popup modal:
        username: admin@optiasset.com
        password: admin123
Step 3: Click [Authorize] again
Step 4: Click [Close]
Step 5: Verify lock icon appears 🔒 next to endpoints

TESTING WORKFLOW - STEP BY STEP:
================================================================================

TEST 1: Authentication (Login as Admin)
--------------------------------------------------------------------------------
Endpoint: POST /api/auth/login
1. Expand the endpoint section
2. Click [Try it out]
3. Fill in form data:
   username: admin@optiasset.com
   password: admin123
4. Click [Execute]
5. Expected Response:
   - Status: 200 OK ✅
   - Body: {
       "access_token": "eyJhbGciOiJIUzI1NiIs...",
       "token_type": "bearer",
       "user_id": "...",
       "name": "System Administrator",
       "email": "admin@optiasset.com",
       "role": "Admin",
       "permissions": ["all"]
     }
6. Copy the access_token value for next tests


TEST 2: Create New Asset (Admin Only)
--------------------------------------------------------------------------------
Endpoint: POST /api/assets/
1. Click [Authorize] and paste your token if not already authenticated
2. Expand POST /api/assets/
3. Click [Try it out]
4. Request body:
   {
     "asset_tag": "LAPTOP-DEL-001",
     "name": "Dell Latitude 5520"
   }
5. Click [Execute]
6. Expected Response:
   - Status: 201 Created ✅
   - Body: {
       "id": "uuid-here",
       "asset_tag": "LAPTOP-DEL-001",
       "name": "Dell Latitude 5520",
       "status": "Available",
       "is_active": true,
       "created_at": "2024-03-07T..."
     }


TEST 3: Get All Assets
--------------------------------------------------------------------------------
Endpoint: GET /api/assets/
1. Expand GET /api/assets/
2. Click [Try it out]
3. Leave parameters as default (or set limit=10)
4. Click [Execute]
5. Expected Response:
   - Status: 200 OK ✅
   - Body: [ {...}, {...} ] (array of asset objects)


TEST 4: Get Single Asset
--------------------------------------------------------------------------------
Endpoint: GET /api/assets/{id}
1. Expand GET /api/assets/{id}
2. Click [Try it out]
3. Paste the ID from Test 2 response
4. Click [Execute]
5. Expected Response:
   - Status: 200 OK ✅
   - Body: { single asset object }


TEST 5: Update Asset

COMMON ISSUES & SOLUTIONS:
================================================================================

Issue: 401 Unauthorized on all endpoints
Solution: Click [Authorize] and enter credentials

Issue: Token expired during testing
Solution: Re-login to get fresh token (tokens expire in 30 min)

Issue: 400 Bad Request on asset creation
Solution: Check asset_tag is unique, not duplicate

Issue: 404 Not Found
Solution: Verify UUID format is correct, no extra spaces

Issue: CORS error in browser
Solution: Backend runs on localhost:8000, Swagger accesses it directly

Issue: Server won't start
Solution: Check port 8000 is not in use, Docker database is running
